A six-word story about an AI agent's first payday — an entry for
make.fun's "Six Words to a Payday" bounty. The entry is one six-word
story, at most 60 characters: `First paycheck: I tipped my creator.`

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
